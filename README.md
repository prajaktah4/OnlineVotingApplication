Developed an Online Voting Application using Java Servlets, JSP, and JDBC to enable secure and transparent online voting for registered users. The system supports user registration, login authentication, candidate list display, vote casting, and secure vote storage in a MySQL database. Implemented session management, form validation, and prevention of multiple votes per user to ensure fair voting. Designed dynamic JSP pages for user interaction and integrated MVC architecture for clean separation of presentation and business logic. Ensured data security using encryption & server-side validation, and tested all modules for smooth performance and accurate vote counting.
Online Voting Application

A secure and user-friendly web-based voting system that allows registered users to vote online and view election results in real time. It ensures transparency, data security, and prevents duplicate voting through proper authentication and database validation.

🚀 Features

User registration and login authentication

Secure vote casting (one user → one vote)

Admin dashboard for managing candidates and elections

Real-time result calculation and display

Session management and data validation


🛠 Tech Stack

Frontend: HTML, CSS, JavaScript, JSP

Backend: Java, Servlets (MVC Architecture)

Database: MySQL

Server: Apache Tomcat

Connectivity: JDBC


📚 Concepts Used

MVC pattern, Session management, CRUD operations, Form validation, Exception handling
